## Method

L0 = raw visible voxels. L1/L2/L3 = unique cells at `floor(pos/{2,4,8})` (matches the renderer's downsample factor; counts are equal to engine LOD vert counts).

Each point binned into box `(bx,by,bz) = (floor(x/XZ), floor(y/Y), floor(z/XZ))`. Box dimensions: `XZ x Y x XZ`, `XZ, Y in {64,128,256,512,1024}`, `Y <= XZ`. Box origins are multiples of box size per axis.

- **non-empty**: boxes with >= 1 point
- **min/max/avg**: points per non-empty box
- **coverage**: boxes intersecting scene AABB; fill = non-empty / coverage
