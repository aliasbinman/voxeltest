================================================================================
code_Archive.txt — removed code reference
================================================================================

Engine is now LW-only (lodworld format `.lw`). This file documents removed
legacy code in case any of it is wanted again. Full content of removed files
is preserved via git history (use `git log -- <path>` + `git show <sha>:<path>`).

--------------------------------------------------------------------------------
SECTION 1 — fully removed source files
--------------------------------------------------------------------------------

src/vox_loader.cpp + vox_loader.h
    Legacy VXL3 reader. Produced `Scene` struct with pointVertices, palette,
    chunkMetas, baked AO + visMask per voxel. Also wrote/read .vxb sidecar
    cache. Replaced by vox2lw (.vox → .lw) + lw_loader runtime.

src/obj_loader.cpp + obj_loader.h + obj_scene.h
    Wavefront .obj mesh loader. Unused in LW path.

src/mesh.h
    Legacy `Vertex` struct (12B: 3×uint16 pos + uint16 aux + uint32 color).
    Used by GpuSubMesh + all per-tech legacy VS. LW uses DiskPoint (8B).

src/vxw.h
    Earlier clustered streamable format (Region + Cluster, 32³ clusters).
    Superseded by lodworld.h (.lw format).

--------------------------------------------------------------------------------
SECTION 2 — removed tools
--------------------------------------------------------------------------------

tools/terrain_gen + terrain_gen.vcxproj
    AWS Terrain Tiles → .vox heightmap baker. Producer-only.

tools/city_gen + city_gen.vcxproj
    OSM Overpass query → .vox city footprint baker.

tools/landscape_gen + landscape_gen.vcxproj
    Kidney-island procedural landscape with biomes, lakes, rivers, Runevision
    analytical erosion.

tools/voxtile + voxtile.vcxproj
    Replicates a .vox in XZ with skirt-fill at chunk perimeters. Made
    kingslanding25.vox (5×5 tile of kingslanding).

tools/vox2vxw + vox2vxw.vcxproj
    Converted .vox to old .vxw clustered format. Superseded by vox2lw.

tools/box_stats + box_stats.vcxproj
    Bucket-stats analyser: voxels per N³ box across LODs. Generated
    docs/box_stats_*.md tables.

SECTION 5 — reference shader snippets (kept for future LW ports)
--------------------------------------------------------------------------------

# Per user: keep PolyAxis, PolyAxisInst, HexSprite shader signatures as
# reference for porting more LW techs later. Full source preserved in git.
# These were the LEGACY (Scene/Vertex) shader entry points.

vsmain_polyaxis:
    Input: voxel from gPolyVoxels via SV_VertexID + gVoxelBase. Emits 18
    vertices per voxel (6 triangles forming 3 axis-aligned quads). Reads
    aoPacked from gPolyAo6 for per-face AO. Uses gChunkBase + voxel pos
    encoded uint16 px/py/pz. PS = psmain_polyvid (shared).

vsmain_polyaxis_instanced:
    Same geometry as vsmain_polyaxis but uses DrawInstanced(18, voxelCount,
    0, pointFirst). SV_InstanceID picks voxel. PS = psmain_polyvid.

vsmain_hex / psmain_hex (DISABLED in source):
    Hex sprite path. 18 verts per voxel forming a hexagonal billboard with
    triplanar shading. Was disabled (#if 0) because it needed a per-instance
    vertex buffer which broke the single-SRV pool consolidation.
